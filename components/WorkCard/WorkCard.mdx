# WorkCard

Клікабельна картка роботи: обкладинка, назва і короткий опис. Уся картка є одним посиланням на сторінку кейсу. Три такі картки стоять у розділі «Роботи» на головній і на сторінці проєктів.

## Параметри

| Параметр | Значення | За замовчуванням |
| --- | --- | --- |
| `title` | назва роботи | обовʼязковий |
| `description` | короткий опис | обовʼязковий |
| `image` | обкладинка, імпортована з `assets` | обовʼязковий |
| `imageAlt` | опис обкладинки для скрінрідера | обовʼязковий |
| `href` | адреса сторінки кейсу | обовʼязковий |
| `className` | додаткові класи для розміщення | порожньо |

## Варіанти і стани

- Default: заливка `accent`, текст `canvas` (14,3:1).
- Hover: заливка стає `ink`, текст лишається `canvas` (17,8:1).
- Focus клавішею Tab: контур `accent` завтовшки 2 px із відступом 2 px, контраст до фону 14,3:1.
- Обкладинка завжди має пропорцію `aspect-cover` (16:9), зайве обрізається по краях.

## Токени

- Кольори: `accent`, `canvas`, `ink`.
- Текст: `text-lead` (назва), `text-small` (опис).
- Радіус: `rounded-card` (кути прямі).
- Пропорція: `aspect-cover`.
- Відступи: `p-4` навколо вмісту, `gap-4` між обкладинкою і текстом, `gap-2` між назвою й описом.

## Коли використовувати

- Для переходу до кейсу з головної або зі списку проєктів.
- Обкладинка лежить у теці `assets` і імпортується в код, не з `public`.
- Опис пиши в одне-два речення: для кого продукт і що він дає.
- Для навігації в меню картка не підходить.

## Як брати в код

```tsx
import cover from "@/assets/fosterlink-cover.jpg";
import { WorkCard } from "@/components/WorkCard/WorkCard";

<WorkCard
  title="FosterLink"
  description="A mobile app that helps people support animals from shelters."
  image={cover}
  imageAlt="FosterLink app screens"
  href="/projects/fosterlink"
/>
```
