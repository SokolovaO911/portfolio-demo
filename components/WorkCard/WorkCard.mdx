# WorkCard

Клікабельна картка роботи: обкладинка, назва і короткий опис. Уся картка є одним посиланням на сторінку кейсу. Три такі картки стоять на головній (на жовтій підложці) і на сторінці проєктів. В кінці опису стоїть стрілка → як підказка, що картка відкривається.

## Параметри

| Параметр | Значення | За замовчуванням |
| --- | --- | --- |
| `title` | назва роботи | обовʼязковий |
| `description` | короткий опис | обовʼязковий |
| `image` | обкладинка, імпортована з `assets` | обовʼязковий |
| `imageAlt` | опис обкладинки для скрінрідера | обовʼязковий |
| `href` | адреса сторінки кейсу | обовʼязковий |
| `imagePosition` | `center`, `top`: яку частину обкладинки лишати, коли її обрізає рамка 16:9 | `center` |
| `showTitle` | `true`, `false`: показувати назву текстом. Вимкни, коли назва вже є на обкладинці (логотип): для скрінрідера вона лишається прихованим текстом | `true` |
| `meta` | рядок над описом: тип і термін, наприклад «Mobile app · 1 month». Пишеться капсом (`text-caption`) | немає |
| `surface` | `canvas`, `accent`: на якому фоні лежить картка. Від цього залежить колір контуру фокуса | `canvas` |
| `className` | додаткові класи для розміщення | порожньо |

## Варіанти і стани

- Default: заливка `accent`, межа `accent`, текст `canvas` (14,3:1).
- Hover: заливка стає `canvas`, текст `ink` (17,8:1), межа `accent` лишається. На жовтій підложці картка в стані default зливається з нею, і її видно лише при наведенні.
- Focus клавішею Tab: контур `outline-focus`. На фоні `canvas` він `accent` (14,3:1), на фоні `accent` (`surface="accent"`) він `canvas` (14,3:1): жовтий контур на жовтому не видно.
- Обкладинка завжди має пропорцію `aspect-cover` (16:9), зайве обрізається по краях.

## Токени

- Кольори: `accent`, `canvas`, `ink`.
- Стрілка → в кінці опису прихована від скрінрідерів (`aria-hidden`).
- Текст: `text-lead` (назва), `text-caption` капсом (`meta`), `text-small` (опис).
- Радіус: `rounded-card` (кути прямі).
- Пропорція: `aspect-cover`.
- Відступи: `p-4` навколо вмісту, `gap-4` між обкладинкою і текстом, `gap-2` між назвою й описом.

## Коли використовувати

- Для переходу до кейсу з головної або зі списку проєктів.
- Обкладинка лежить у теці `assets` і імпортується в код, не з `public`.
- Опис пиши в одне-два речення: для кого продукт і що він дає.
- Для навігації в меню картка не підходить.

## Як брати в код

```tsx
import cover from "@/assets/fosterlink-cover.jpg";
import { WorkCard } from "@/components/WorkCard/WorkCard";

<WorkCard
  title="FosterLink"
  description="A mobile app that helps people support animals from shelters."
  image={cover}
  imageAlt="FosterLink logo"
  href="/projects/fosterlink"
  showTitle={false}
  meta="Mobile app · 1 month"
  surface="accent"
/>
```
