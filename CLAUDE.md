## Токени

Єдине джерело значень: блок `@theme` у `app/globals.css`. Стандартні палітра, розміри тексту й радіуси Tailwind скинуті, тому працюють лише класи нижче.

- Кольори: `canvas` (фон), `surface` (поля форми), `line` (декоративні лінії), `accent`, `ink`, `ink-muted`, `danger` (помилка).
- Межа поля форми: `ink-muted` (контраст не менше 3:1), не `line`.
- Текст: `text-display`, `text-heading`, `text-lead`, `text-body`, `text-small`, `text-caption`.
- Радіуси: `rounded-control`, `rounded-card`. Обидва 0: кути прямі.
- Пропорції: `aspect-portrait` (3:4), `aspect-cover` (16:9), `aspect-case-logo` (2:1).
- Відступи: 8, 12, 16, 24, 32 px (числа 2, 3, 4, 6, 8 у класах). Між великими секціями: `section`.
- Ширина контенту: `max-w-content` (1120 px), колонка тексту: `max-w-prose` (664 px).
- Точка перелому `tablet` (896 px) між `md` (768) і `lg` (1024): планшет у ландшафті.
- Ширини розкладки (у відсотках від батьківського блока): `w-hero-photo` (19/60), `w-hero-gap` (1/15), `w-cards` (75%), `w-cards-offset` (20%), `w-about-photo` (1/3), `w-menu` (50%).
- Шрифт: Helvetica Neue, Helvetica, Arial (системний стек).

## Компоненти

Усі лежать у `components/<Назва>/` разом з історією (`.stories.tsx`) і документацією (`.mdx`). Дивитися в Storybook (`npm run storybook`). Змінив компонент: онови історію й docs у тому ж кроці.

- `Button`: прямокутна кнопка або посилання (`href`). Варіанти `primary`, `secondary`, розміри `md`, `lg`, стан `disabled` через `aria-disabled` і пояснення `disabledReason`.
- `FormField`: поле форми з підписом над ним. Параметри `error`, `errorMessage`, `multiline`, `required` (зірочка після підпису).
- `WorkCard`: клікабельна картка проєкту з обкладинкою `aspect-cover`. Параметри `imagePosition`, `showTitle`, `surface` (`canvas` або `accent`: від фону залежить колір фокусу).
- `Navigation`: меню сайту. На вузькому екрані згортається в кнопку «Menu», Escape закриває.

## Правила

- Кнопка: прямокутна, жовта (`accent`), текст `canvas`. Мазок пензля зі старого сайту не переносимо.
- Картки проєктів: жовті (`accent`), текст `canvas`; при наведенні заливка `canvas`, текст `ink`, межа `accent` лишається.
- Файл резюме лишається зі старим прізвищем (Olha_Okulevych_Resume.pdf), на сайті ім'я Olha Sokolova.
- Hex, стандартні класи Tailwind поза системою і значення в квадратних дужках заборонені.
- Виняток для декору: для декоративних картинок (рука, скріпка, лінія; `alt=""`, `aria-hidden`) дозволені класи позиціювання й трансформації поза токенами: дробові ширини й зсуви (`w-1/5`, `left-1/16`), `rotate-*`, `translate-*`, `-scale-x-100`, `z-10`. Для решти елементів діє правило вище.
- Виняток для смуг на всю ширину: декоративні блоки без вмісту (жовта підложка під картками, `aria-hidden`) можуть виходити за межі контенту через `left-1/2`, `w-screen`, `-translate-x-1/2`. Для решти блоків ширини задаються токенами (`w-hero-photo`, `w-cards` та ін.).
- Виняток для фото з нахилом: одне змістовне фото (портрет на сторінці About) може мати легкий нахил `rotate-2` як декоративний прийом. Інші трансформації й кути для змістовних зображень не дозволені.
- Решту правил заповнимо далі.
