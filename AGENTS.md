# Інструкції для агентів

Портфоліо Olha Sokolova: Next.js (App Router), TypeScript, Tailwind CSS v4, Storybook.

## Команди

- `npm run dev`: сайт локально.
- `npm run build`: збірка Storybook у `public/storybook` і сайту.
- `npm run storybook`: Storybook локально.

## Правила

Правила дизайн-системи (токени, відступи, компоненти, винятки) і робота з Git описані в `CLAUDE.md`. Читай його перед змінами.
