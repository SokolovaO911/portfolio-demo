# Портфолио UI/UX-дизайнера: позиционирование и план сайта

Nov 9, 2026 · @Olha

План сайта-портфолио в четырёх разделах; всё, чего не хватает, вынесено в раздел 4.

## 1. Позиционирование одним предложением

> Junior UI/UX-дизайнер, который создаёт приложения и платформы с социальной значимостью для людей, которым нужна помощь, чтобы они доходили до результата без лишних шагов.

## 2. Страницы сайта

| Страница | Назначение |
| --- | --- |
| Главная | За минуту показывает, кто ты, каким людям помогают твои продукты и куда смотреть дальше. |
| Работы | Собирает три проекта в одном месте и ведёт к нужному кейсу. |
| Кейс (по одной странице на проект) | Рассказывает путь проекта от задачи до интерфейса и показывает твою роль и артефакты. |
| Обо мне | Рассказывает личную историю и опыт, чтобы было понятно, откуда твой интерес к таким продуктам. |
| Контакты | Даёт работодателю все способы связаться с тобой и скачать резюме. |
